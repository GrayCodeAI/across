# Clean-room decisions

Across was implemented independently. No third-party source code was copied.

## Approach

1. Observable behavior of existing tools was studied from public documentation and CLI output.
2. Behavior specifications were written.
3. Independent implementations were authored in Go.

No unlicensed code was reproduced. No proprietary implementation details were copied.

## Provenance

Every engineering record in Across traces back to a source. When historical provenance cannot be recovered, it is stored as `unknown` — never guessed.
